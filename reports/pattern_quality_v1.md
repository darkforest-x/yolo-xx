# Pattern Quality v1 — 只用几何特征

**Phase 2 / stage 1** · 2026-08-06
**预注册**：`reports/prereg_pattern_quality_v1.json`（锁定于建模之前）
**性质**：未使用任何盈亏标签，未做收益回测，未改 YOLO 权重，未消耗 holdout。
**按本仓口径：给数字，不下判决；数字不粉饰。**

---

## 1. 设置

| 项 | 值 |
|---|---|
| 标签 | owner 分级 287 条（A 121 / B 96 / C 8 / not_a_pattern 62） |
| 特征 | 10 个几何量（`fast_spread` `full_spread` `ma_spread_pct` `cluster_width_atr` `atr_pct` `slow_slope_12` `order_score` `down_order_score` `trend_order_score` `dense_run_bars`） |
| 切分 | **GroupKFold(5) by symbol** —— 同一币种不跨训练/验证 |
| 模型 | LogisticRegression（标准化+L2）、LightGBM（num_leaves 7 / min_child 15 / 200 树 / lr 0.05） |
| 调参 | **无**。seed=0，不搜超参、不搜阈值 |
| embedding | **未使用**（stage 2） |

---

## 2. 结果

### T1 — 是不是形态（225 vs 62）

| 指标 | logreg | LightGBM |
|---|---|---|
| CV AUC | **0.7313** | 0.7049 |
| Cohen κ @0.5 | **0.0409** | 0.2918 |
| 准确率 @0.5 | 0.7700 | 0.7909 |

- 多数类基线：0.784（**准确率 0.77 低于「全判为形态」**）
- 置换检验（200 次）：null 均值 0.4710、p95 0.5654 → **p = 0.0050**
- **最强单特征 `full_spread` 单独 AUC = 0.7309**
- **模型相对最强单特征的增量 = +0.0004**

logreg @0.5 的混淆矩阵：

|  | 预测 非形态 | 预测 形态 |
|---|---|---|
| **实际 非形态（62）** | **4** | 58 |
| **实际 形态（225）** | 8 | 217 |

62 个「不是形态」里只挑出 4 个。κ=0.041 意味着在 0.5 阈值下与人工判断的一致性接近随机。

### T2 — 是不是 A 级（121 vs 104，仅在形态子集内）

| 指标 | logreg | LightGBM |
|---|---|---|
| CV AUC | **0.5888** | 0.5546 |
| Cohen κ @0.5 | 0.2049 | 0.0665 |
| 准确率 @0.5 | 0.6044 | 0.5378 |

- 多数类基线：0.5378
- 置换检验：null 均值 0.4728、p95 0.5695 → **p = 0.0299**
- **最强单特征 `slow_slope_12` 单独 AUC = 0.6439**
- **模型相对最强单特征的增量 = −0.0551（模型比一个特征还差）**

---

## 3. 三个必须一起读的数字

1. **T1 的 0.7313 全部来自一个特征。** `full_spread` 单独就有 0.7309，十个特征的模型只多出
   0.0004。这不是「模型学到了组合」，是「一个特征就是全部信号」。
2. **T1 的 AUC 与它的可用性脱节。** AUC 0.73，但 κ=0.041、62 个负样本只识别出 4 个，
   准确率（0.77）还低于「全部判为形态」（0.784）。排序上有信息，落到判定上几乎没有。
3. **T2 的模型不如单特征**（0.5888 vs 0.6439），且 p=0.0299
   —— 按本项目质量标准（置换 p<0.01）**不过线**。
   0.589 这个数值本身也需要警惕：CLAUDE.md 的头号警告就是
   「把 AUC 当成功标准 → v1 的教训是 AUC 0.59 照样亏钱」。

---

## 4. 特征方向（读数，非结论）

T1 全量拟合的 logreg 系数（绝对值排序）：

| 特征 | 系数 | 方向读法 |
|---|---|---|
| `atr_pct` | **+0.808** | 波动越大越像形态 |
| `slow_slope_12` | −0.733 | 慢均线斜率越平/越负越像形态 |
| `full_spread` | **+0.444** | **spread 越大（越不密）越像形态** |
| `cluster_width_atr` | +0.318 | 簇越宽越像形态 |

`full_spread` 与 `cluster_width_atr` 的**正号**，与 owner 分级数据独立吻合：
A 级样本 `fast_spread` 中位 0.00592，not_a_pattern 中位 0.00286
（`reports/quality_grading_round1.md` §3）。
两条独立路径都指向：**机械「越密越好」的方向是反的。**

T2 系数首位是 `cluster_width_atr`(+0.347) 与 `slow_slope_12`(−0.295)，
但整体判别力弱，方向读数意义有限。

---

## 5. 失败退出条件的判定

V5 Phase 2 的退出条件是「两个任务的 CV AUC 均不显著优于置换基线」。
本轮 T1 p=0.0050、T2 p=0.0299，**均优于置换**，故**未触发**该条件。

但退出条件之外，本轮暴露的是另一个问题：**多特征模型相对单特征没有增量**
（T1 +0.0004，T2 −0.0551）。当前几何特征集里的信息，一条阈值规则就能取走。

---

## 6. 下一个可以动的变量（不含判决）

按成本从低到高：

1. **stage 2：embedding 增量**（预注册已定义）。当前几何基线 T1=0.7313 / T2=0.5888，
   增量是否存在可直接测。注意前提仍待验：teacher 检出 89.4% 被 owner 否。
2. **扩标**。T2 的 121 vs 104 在 GroupKFold 下每折仅约 45 个样本；
   C 级仅 8 条使三分类不可行。扩标同时能缓解 §3 的功效问题。
3. **换特征族**。当前 10 个几何量全部取自信号 bar 的**瞬时截面**，
   不含形态的时间演化（如密集段的收敛速率、前期趋势幅度、突破前的量能路径）。
   owner 判断很可能依赖这些，而截面特征无法表达。
4. **重审 T1 的标签构成**。62 个 not_a_pattern 中 42 个来自 teacher 检出、
   20 个来自 owner 旧框，两者成因不同，混为一类可能压低可分性。

## 7. 限制

1. n=287，单人评分，无评分者间一致性复核。
2. 样本按 `fast_spread` 五分位分层抽取，类别比例不代表 Library 总体，
   AUC 不可外推为线上表现。
3. GroupKFold(5) 下 T2 每折验证集约 45 条，AUC 的折间方差未报告。
4. `teacher confidence` 被排除（仅 47 条有值，会退化为 source 指示变量）。
5. 未做阈值搜索——κ 与准确率均在固定 0.5 下计算，非最优点。
6. 全程未使用收益类信息，故本报告不含任何盈利性结论。
