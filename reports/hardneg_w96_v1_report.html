二、三类样本长什么样

看第二张就能发现 v1 的缺陷：配对背景是明显的上涨/横盘，跟正样本的"下跌+均线收拢"一眼就能区分。 第三张的 hard 反例也没对上语境。这就是后来 v2 要重做的原因。

三类样本的产生规则

  • 正样本：owner 的 1361 个 short 框，每个生成一个窗口终点 = 框结束 + right_context（按 box_id 散列到 0/8/16/24 根）。 窗口内所有完整可见的 owner 框都写进标签；被边缘截断的框会让整个样本作废。
  • 配对背景：同币种、同 split、同 right_context，在 ±1~365 天里找一个终点，要求 200/96 两个窗口都不与任何 owner 框重叠， 且不触发冻结的密集规则。找不到就正负一起丢弃。
  • hard 反例：条件反过来 —— 触发密集规则 + 无 owner 框重叠 + 模拟做空确实亏损。 第三条是防止把 owner 漏标的真机会当成反面教材。

所有改变时间/位置/红绿语义的增强全部关闭：mosaic、mixup、cutmix、翻转、平移、缩放、旋转、HSV、BGR、multi-scale、erasing 全为 0。 训练前靠 portable receipt 逐图逐标签验 SHA-256，审计不过拒绝训练。

四、mAP50 是怎么算的

每个 epoch 结束，在 val 集（1381 张图、305 个真框）上：

  1. 模型输出框和置信度，按置信度从高到低排序
  2. 每个预测框与真框算像素 IoU，≥0.5 算命中，一个真框只能被匹配一次
  3. 扫过所有阈值画 precision-recall 曲线，曲线下面积 = AP；单类别所以 mAP50 = AP
这个数字有两个大问题，不能直接跟旧模型的 0.596 比。
① 考卷不一样：旧模型 val 是 554 张（5 张里 2.5 张是正的），新模型 val 是 1381 张（5 张里 1 张）。新考卷难得多。
② 两张考卷都不是实盘：实盘连续扫描时 40 个窗口才有 1 个含真框。所以真正该看的是"连续扫描精度"。

五、回测怎么做的

第一步：检测 → 信号

拿一批扫描图跑推理，固定 conf=0.30 / iou=0.70（冻结阈值，不按结果调）。 每个检测框记：币种、available_at、置信度。

关键：available_at = 该输入窗口最后一根 K 线的收盘时间，也就是这张图最早可能存在的时刻。 不是框的右边界 —— 框画在图中间不代表信号那时可用，整个窗口闭合前这张图根本不存在。

第二步：信号 → 交易（无前视）

  • 进场：15m（或 30m）序列上第一根开盘时间 ≥ 信号时间的 K 线，按开盘价做空
  • ATR：14 周期 Wilder，严格用进场那根之前的 K 线计算
  • 止盈 = 进场价 − 5×ATR，止损 = 进场价 + 2×ATR
  • 逐根前进：先查最高价是否触及止损，再查最低价是否触及止盈。 同一根同时触及两条线，一律按止损计（最悲观）
  • 96 根未出结果按收盘价平仓，记为超时
  • 成本 0.06% round-trip（maker 口径）
  • 同币种同时只持一仓 —— 不去重会把同一波行情重复计数，实测能把 PF 从 0.96 虚抬到 1.56

盈亏平衡胜率 = 2/(5+2) = 28.6%。模拟器有 8 个测试盯着：进场不早于信号、ATR 不看未来、 同根双触按止损、超时按收盘、成本扣除、数据不足时丢弃而非猜测。

七、为什么失败 + 下一步

看第二节那三张图就清楚了：v1 的反例跟正样本的语境完全没对上。 量化对比 —— 正样本在窗口末端价格位于 120 均线下方 2.99%、99% 在下方； v1 反例是 −0.14%、只有 53% 在下方。模型学到的是"拒绝上涨和横盘"，不是"拒绝相似形态"。

v2 已经在训：先量出正样本语境的 p10–p90 区间（距 120 均线 −6.6%~−1.0%、前 48 根跌 8%~1.1%、 均线带宽 0.006~0.051），只收落在这个区间内的反例。筛选漏斗 25658 候选 → 5511 语境匹配 → 3766 做空亏损。 76% 是 v1 没选过的新窗口，语境指标已对齐（−2.41% vs 正样本 −2.99%，100% 在均线下方）。
