# 跨周期标签必须保持物理时长

- **问题**：直接在 1m/3m/5m/15m 上复用 MA20/60/120 与 5–12 根 dense，会让每个模型观察完全不同的时间尺度，无法归因分辨率差异。
- **死胡同**：只把 CSV 文件名和 `timeframe` 改掉，仍把均线周期与 dense 长度写死为 bar 数；结果看似是周期对比，实际同时改变了形态定义。
- **有效路径**：配置统一使用真实分钟数，再显式换算成各周期 bar 数；MA 必须整除，dense 最短时长向上取整，最长时长与合并间隔向下取整，并把请求值和解析值同时写入 manifest。
- **通用规则**：跨周期实验先固定物理时间语义，再改变采样分辨率；所有舍入必须机器可读，不能隐藏在代码默认值里。
- **牵连**：`src/yolo_xx/specs.py`、`data.py`、`render.py`、`labels.py`、dataset CLI 与 schema v2 manifest。
