# 历史框的时间不是检测可用时间

- **问题**：窗口内任意位置的框都有自身起止时间，但模型只有在整个输入窗口闭合后才能完成这次检测；若把框结束时间当成信号时间，就会制造前视。
- **死胡同**：只在 manifest 保存 `box_end_time`，再把检测事件映射回该时刻。这个时间描述了图中对象，却没有描述模型何时获得完整输入。
- **有效路径**：同时保存对象的 `box_*_time` 与检测的 `available_at`，并强制每个框的 `available_at = window_end_close_time`。中部框可以用于多位置训练，但不能回填成历史实时检测。
- **通用规则**：任何滚动窗口模型先定义“输入何时完整”，所有输出的可用时间取这个时刻；对象时间只作定位与去重元数据。
- **牵连**：`src/yolo_xx/dataset.py`、`src/yolo_xx/predict.py`、schema v2 `dataset_manifest.json`、跨窗口事件映射、无前视测试。
